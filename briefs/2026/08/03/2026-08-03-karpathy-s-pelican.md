你是资深产品工程师。请把下面这条产品灵感做成一个可以本地运行的 MVP。

## 灵感

把热门开源项目做一遍
开发者贴入热门仓库，从失败测试开始逐步补齐代码，亲手做出核心机制的缩小版。

## 产品概念

开发者看到一个突然走红的开源仓库时，往往能读懂介绍，却很难判断核心设计究竟解决了什么。直接克隆完整项目，通常会先撞上复杂依赖、配置和大量已经写好的代码，最后只剩下照着运行。 用户贴入仓库地址，选择想理解的功能，例如数据处理、模型训练或命令行流程。产品先抽出一个最小可运行目标，创建本地练习仓库，并故意放入一组会失败的测试。每个练习只给出当前需要补齐的接口、少量样例输入和失败结果。 用户写完一小段代码后，测试立刻显示哪里通过、哪里仍不符合预期。通过后才会解锁下一步，并在旁边展示原仓库中对应模块为何需要存在。完成若干步骤，用户得到一个可以独立运行的缩小版项目，还能逐项查看它与原项目的取舍差异。 第一版优先处理结构清晰、测试可运行的公开仓库，不尝试自动复刻分布式部署、私有数据或作者的全部环境。它的交付物不是一篇项目摘要，而是一条能亲手走完的复现路径。

## 为什么是现在（有事实支撑）

Karpathy’s Pelican 在 8 月 3 日观察时位列 Hacker News 第 1，获得 410 points 和 326 comments。 热门项目先引发密集讨论时，开发者更容易遇到“看懂介绍，却无法亲手验证核心机制”的落差。

## 方向判断（以下为模型推断，未经独立验证）

目标用户：主要用户是能读代码，却还不熟悉目标领域的开发者。他们通常刚在社区看到热门仓库，想在投入整个周末前弄懂核心机制。此时 README 已经读过，直接克隆却被环境和目录结构拖住。他们需要一个一小时内可完成的小目标，用亲手实现来判断项目是否值得继续深挖。

最小切入点：入口接收公开 GitHub 仓库地址，并固定到具体提交。通过 Git Trees 与 Contents API 取得目录、清单文件和目标源码。 首期只支持 Python 与 TypeScript，并要求原仓库已有可运行测试。系统先读取包清单、测试配置和样例，再选取一个依赖较浅的公开接口。练习仓库复制最小依赖闭包，挖空目标实现，并保留原测试改写出的行为断言。所有代码在隔离容器内运行，超时、网络和文件写入均受限。暂不生成跨服务、GPU 训练或依赖私有数据的练习。

最强反方：自动生成的测试可能只复刻表面输出，无法证明用户理解了原设计。若原仓库测试不足，系统只能从实现反推断言，容易把偶然行为写成正确答案。依赖裁剪也会改变语义，尤其涉及异步、缓存、文件系统和外部服务时。运行陌生代码还要承担供应链、资源滥用和数据外传风险，因此必须使用隔离容器并默认断网。许可证也可能限制源码改写与再分发。只要练习频繁无法启动，或答案与原项目脱节，用户会迅速失去信任。

以上是模型基于灵感本身与已核验事实的推断，请当作方向假设与真实约束对待：不要默认「最强反方」已被解决，也不要据此在产品里写下确定性结论。

## 以小博大（模型推断）

首批流量可直接来自热门仓库讨论页、技术社区和作者转发。每次选一个正在被讨论的仓库，发布可公开试玩的首关，并展示失败测试到通过结果。练习页保留原仓库与提交链接，方便维护者核对和纠错。再把完成者的缩小版实现做成可分享成果页，让学习记录自然回流到同一仓库话题。

## 竞品与缝隙（模型推断）

- DeepWiki：DeepWiki 已能为公开仓库生成架构图、文档、源码链接和问答，适合先建立代码库全貌。 用户还能提交自己的公开仓库，并围绕陌生模块追问实现细节。它解决的是“读什么”和“代码在哪里”，主要交付仍是可阅读的知识页面。用户无需亲手重建关键接口，也不会经历测试从失败到通过的过程。这里的缝隙是把仓库理解变成可验证的编码练习，而非继续增加摘要深度。产品需要给出缩小后的依赖闭包、待补接口和逐步测试。完成后还要把练习实现与原模块并排解释。若仅生成另一套文档或聊天入口，就很难与 DeepWiki 拉开差异。
- CodeCrafters：CodeCrafters 已把 Redis、Git、SQLite 等系统拆成分阶段挑战，用户在自己的编辑器写代码，再通过测试获得反馈。 它已经验证了“亲手重建加自动判题”是一种完整学习体验。其课程围绕预先制作的固定项目，测试、提示和关卡由平台长期维护。用户不能贴入当天走红的任意仓库，立即获得对应核心机制的缩小版。这里的机会不是重做通用编程训练，而是缩短热点仓库到可练习课程的制作周期。生成结果还应固定原仓库提交，保留模块出处与取舍说明。真正困难的是自动判断哪些行为值得保留，并让测试不会泄露答案。若课程质量需要大量人工修订，任意仓库入口就会退化成精选课程目录。

## 怎么赚钱（模型推断）

按月订阅收费，包含固定数量的仓库解析和练习生成额度。较重的依赖构建与测试运行按次计费，公开生成的精选练习可免费体验。
