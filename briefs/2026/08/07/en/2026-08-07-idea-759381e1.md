## Idea

Email Verification Code Autofill
When a website asks for an email verification code, find the matching message locally and fill in the code with one click—without switching back and forth to email.

## Product concept

When a browser detects that a page is waiting for an email verification code, it searches only local email for recent messages matching the domain and request time. The user can fill in a code with one click, and when several codes are available, each is labeled with the site it belongs to.
