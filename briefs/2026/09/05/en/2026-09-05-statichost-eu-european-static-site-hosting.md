## Idea

European Static Site Release Gate
Before a static site launches on European hosting, it traces where page-runtime data goes and blocks third-party requests that still cross borders.

## Product concept

Before a static site goes live on European hosting, this release gate opens preview pages from multiple European locations and traces requests from fonts, analytics, and forms. If data still flows outside the region, it identifies the code or dependency responsible, then blocks the release or replaces the request with an approved endpoint.
